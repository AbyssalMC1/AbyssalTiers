# Abyssal Tiers

Static Minecraft PvP tier-list site designed for GitHub Pages.

## Publish
1. Extract this ZIP.
2. Upload every file and folder inside `AbyssalTiers` into the root of your GitHub repository.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. Open the Pages URL GitHub provides.

## Customize
- Home page and gamemode cards: `index.html`
- Colors and layout: `style.css`
- Home page search: `script.js`
- Gamemode leaderboards: each `<gamemode>.html` file
- Mode icon images: `images/` (SVG files)

Each leaderboard currently has five placeholder/example players and example tiers. Replace them with your real community rankings. The rankings are not verified.

Gamemodes included: Sword, Axe, Mace, UHC, DiaPot, NethPot, SMP, Crystal, Spear, Elytra, Trident, MoneySMP, CreeperPvP, KPvP, CocoPvP, CartBow, DiaSMP.


## Player profiles
Click a player name on any gamemode leaderboard to open their profile. Each profile lists all 17 gamemodes and the player's example tier for each. These are editable example values, not verified rankings. Update both the relevant gamemode page and the player's profile HTML when changing tiers.
Players included: X_AbyssalMC_X, CocoMineru, Femyth, seby88213, Kappa8081.
